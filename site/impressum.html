Gewährleistungsausschluss für die Software

cyberviber wird im Rahmen der MIT-Lizenz „wie besehen“ und ohne jede Gewährleistung bereitgestellt. cyberviber install verändert die Konfiguration von Claude Code (~/.claude/settings.json, mit einmaliger Sicherungskopie) und gegebenenfalls von Mistral Vibe und richtet einen Hintergrunddienst ein; cyberviber uninstall macht das rückgängig. Das Aufspielen der Firmware auf die Hardware geschieht auf eigene Verantwortung.
