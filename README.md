# cyberviber

Claude Code session manager for a 2.4" ESP32 touch display (ESP32-2432S024, 240×320). It lists all running Claude Code sessions, shows their state (needs you / ready / working / idle), and tapping one brings its terminal to the front: zellij pane, Tabby tab or Ghostty window.

Status: the Mac daemon, the browser simulator, the jump to the terminal, the USB link and the firmware (layout A · waybar, Tokyo Night) work. The other layouts, themes and the settings screen come next. Design and architecture are in [spec.md](spec.md); the layouts are in [design/index.html](design/index.html).

## Install (macOS)

From source:

```sh
go install github.com/d135-1r43/cyberviber/cmd/cyberviber@latest
~/go/bin/cyberviber install
```

Or download a binary from the [releases](https://github.com/d135-1r43/cyberviber/releases) (arm64, amd64, universal). The binaries are not notarized: run `xattr -d com.apple.quarantine cyberviber` after extracting.

`cyberviber install`:
- adds hooks to `~/.claude/settings.json`, keeping all other hooks. A backup is written once to `settings.json.cyberviber-backup`.
- installs the launchd agent `dev.cyberviber.daemon`, which logs to `~/Library/Logs/cyberviber.log`.
- installs the Tabby plugin, if Tabby is present. Reload or restart Tabby once afterwards.

`cyberviber uninstall` removes all of it.

## Use

```sh
cyberviber status    # session table
cyberviber sim       # browser simulator with live sessions: http://127.0.0.1:7337/
cyberviber release   # free the device's serial port for 60 s (e.g. to flash it)
cyberviber version
```

Config: `~/.config/cyberviber/config.toml` (`port`, `idle_after`, `serial`, `baud`).

## Firmware

Board: ESP32-2432S024R (2.4" TFT, XPT2046 resistive touch, CH340 USB). [PlatformIO](https://platformio.org) builds and flashes it:

```sh
uv tool install platformio                       # or: pipx install platformio
cyberviber release 120                           # the daemon frees the port
pio run -d firmware -t upload
cyberviber release 1                             # reattach right away
```

On first boot the device asks for a touch calibration (tap the four arrow tips); it is kept in flash. Hold a finger on the screen while plugging it in to calibrate again. `pio run -d firmware -e cyd24r-touchlog` builds a variant that reports raw touch points to the daemon log. Fonts are generated by `firmware/tools/gen-fonts.sh`.

## Continue on another Mac

```sh
git clone git@github.com:d135-1r43/cyberviber.git && cd cyberviber
go test ./...
go install ./cmd/cyberviber && ~/go/bin/cyberviber install   # hooks, daemon, Tabby plugin
# reload/restart Tabby once, then:
~/go/bin/cyberviber sim                                      # http://127.0.0.1:7337/
```

On the old Mac, run `~/go/bin/cyberviber uninstall` if it should stop reporting.
